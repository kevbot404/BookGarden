## Features

- EPUB file upload and reading
- Personal library stored locally with IndexedDB
- Sample books included (Crime and Punisment & The Adventures of Sherlock Holmes)
- Table of contents navigation
- Adjustable font size
- Font family selection
- Line height adjustment
- Theme switching (light, dark, sepia)
- Text alignment (left, center, right, justify)
- Adjustable reader width and height
- View mode switching (scrolled / paginated)
- Previous/next chapter navigation
- Keyboard navigation (arrow keys)

## Built With

- [Vite](https://vitejs.dev/) - Build tool and dev server
- [epub.js](https://github.com/futurepress/epub.js/) - EPUB rendering engine
- [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API) - Client-side storage for the personal library
